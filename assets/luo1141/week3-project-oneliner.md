# AgentPay SDK — 项目一句话描述

## 🚀 核心定位

**AgentPay SDK — 让 AI Agent 安全自主支付的开发者工具包**

---

## 英文描述

A minimal SDK that wraps **x402 + Smart Account + Session Key** so AI agents can make secure on-chain payments with human-defined budgets and permissions.

---

## 中文详细说明

AgentPay SDK 是一个轻量级的开发者工具包，封装了 **x402 协议**、**Smart Account** 和 **Session Key** 三大核心能力，使 AI Agent 能够：

1. **安全支付** — 基于 x402 协议发起标准化链上支付请求
2. **预算控制** — 人类通过 Session Key 为 Agent 设定支付额度上限
3. **权限隔离** — 每个 Agent 拥有独立的支付权限，互不干扰
4. **即插即用** — TypeScript SDK，3 行代码即可集成

---

## 价值主张

| Before (现状) | After (使用 AgentPay SDK) |
|---------------|---------------------------|
| Agent 无法自主支付 | Agent 可安全发起支付 |
| 无预算控制机制 | 人类定义 Agent 支付上限 |
| 每个开发者重复造轮子 | 标准化 SDK，开箱即用 |
| 支付权限混乱 | Session Key 精细权限控制 |

---

## 目标场景

- AI Agent 购买 API 访问权限
- Agent 订阅数据服务
- Agent 间支付协作费用
- Agent 自动化采购和结算

---

> **一句话总结：让 AI Agent 像人类一样安全、可控地花钱。**
