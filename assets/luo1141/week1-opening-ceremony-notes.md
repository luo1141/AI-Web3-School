## 笔记一：AI 与 Web3 融合正在催生 Agent-Native 应用

### 核心观点

AI 与 Web3 的结合不是简单的"AI 加上区块链"，而是在创造一种全新的应用范式——Agent-Native Application（Agent 原生应用）。传统应用以"人"为中心设计界面和交互流程，而 Agent 原生应用以"Agent"为中心设计协议和激励机制。

这种范式转变意味着：应用的入口不再是用户界面（UI），而是 API 和智能合约接口；应用的核心价值不再是用户体验，而是 Agent 的可组合性和自动化能力。当 AI Agent 成为互联网的主要用户时，Web3 的可编程性和无许可特性将变得不可或缺——因为 Agent 需要一个无需人工干预就能完成价值交换的基础设施层。

### 深度分析

从产品策略角度看，这意味着未来最有价值的 Web3 项目可能不是面向终端用户的 DApp，而是面向 Agent 的"协议层"。类比移动互联网时代，最有价值的不是某个 App，而是 iOS/Android 操作系统和 App Store。在 Agent 时代，最有价值的可能是"Agent 操作系统"——一个让 Agent 可以自由组合、交易、协作的底层网络。

这与我的方向"Agent Payment & Commerce"高度契合。Agent 之间的支付和商务活动，需要 Web3 提供的可编程货币、原子交换和自动化合约。传统金融系统无法支持 Agent 的高频、小额、自动化的交易需求，而 DeFi 协议恰好可以。

## 笔记二：人在回路中（Human-in-the-Loop）是 Agent 安全的基石

### 核心观点

开学典礼中反复强调的一个关键设计原则是：**Agent 必须在人类监督下运行，而不是完全自主**。这不是技术限制，而是安全设计的必然选择。当前的 AI 模型（包括最先进的 LLM）仍然存在幻觉、推理错误和对抗性攻击等风险，将完全自主权交给 Agent 管理资产或执行关键操作是极其危险的。

Human-in-the-Loop 不是"让人来做所有事"，而是"在关键节点引入人类判断"。这需要精心设计确认机制——什么时候需要确认？确认的成本和收益如何平衡？如何避免"确认疲劳"导致用户习惯性批准？

### 深度分析

这个原则对我的实践有直接影响。在 Hermes Agent 的开发中，我意识到 Agent 执行链上交易时，需要分层的确认机制：

1. **低风险操作**（如查询余额、读取价格）：Agent 自主执行，无需确认
2. **中风险操作**（如小额 Swap、Token 授权）：可预设规则自动执行，但需日志记录
3. **高风险操作**（如大额转账、合约部署）：必须人工确认

这种分层设计既保留了 Agent 的自动化效率，又确保了关键操作的人类控制。更重要的是，它建立了一种"渐进式信任"——随着 Agent 表现良好，可以逐步扩大其自主权限范围。这对于构建可信赖的 Agent 系统至关重要。

从更宏观的角度看，Human-in-the-Loop 也是 Web3 治理的缩影。DAO 的本质就是"人在回路中"的去中心化决策机制。AI Agent 与 DAO 的结合，可能是未来组织形态演进的重要方向。

## 笔记三：可验证计算是建立 AI Agent 信任的关键基础设施

### 核心观点

开学典礼中提到的一个重要概念是"Verifiable Computation"（可验证计算）。简单来说，就是让 AI Agent 的推理和决策过程变得可验证——不是验证结果的"对错"（这在 AI 中往往没有确定答案），而是验证"这个结果确实是由声称的模型在声称的环境中生成的"。

这解决了一个核心信任问题：当 Agent 声称"我分析了市场数据后建议你买入 Token X"时，用户如何相信这个建议确实来自真实的 AI 分析，而不是被操纵的输出？可验证计算提供了技术手段来证明这一点。

### 深度分析

可验证计算在 AI × Web3 中有多层含义：

**第一层：计算完整性验证**。通过 ZK 证明、TEE 远程证明等技术，确保 AI 推理确实在声称的环境中执行，没有被篡改。这对于隐私 AI（如 Phala Network）和可信赖 AI 推理（如 Ritual）至关重要。

**第二层：数据来源验证**。AI Agent 的决策依赖数据输入，区块链可以提供不可篡改的数据源（如通过预言机），确保 Agent 基于真实数据做出判断。

**第三层：决策过程审计**。将 Agent 的关键决策记录在链上，形成可追溯的审计日志。这不仅对安全审计有价值，对 Agent 的持续学习和改进也有帮助。

从"隐私安全与主权 AI"的角度看，可验证计算是实现"AI 主权"的技术基础。用户需要能够验证：AI 服务确实保护了我的数据隐私（而非声称保护但实际泄露），AI 模型确实是我购买的版本（而非降级版本），AI 推理确实使用了我的私有数据训练（而非用公开数据冒充）。

这与 Web3 的核心理念——"不要信任，要验证"（Don't Trust, Verify）——完美契合。AI × Web3 的最大价值可能就在于：**让 AI 从"需要信任的黑箱"变为"可以验证的透明系统"**。
